请在当前 RTX 4070 Super 电脑上直接执行下面任务和所需命令；不要只告诉我命令，也不要开始训练模型。

1. 将这台电脑上“人工修改约 150 张之后”的旧最终 PeakTruthLab 数据，与新发布的 4500 张 v2 数据安全合并。
2. 从合并后的最终数据生成一套样本级分层随机 `train/val/test`，并额外生成一套按完整来源留出的跨域实验清单。

## 三、合并规则

创建新的最终目录，例如：

`PeakTruthLab/datasets/PeakTruthLab_final_merged_20260814`

合并旧最终数据与新 4500 张 v2 数据：

- 保留每张图的全部人工框，同一图片的多个框不得拆开或丢失。
- `True_Peak` 与 `OUT_FIG` 语义保持不变；无框图保留为 Seed 假峰。
- 统一为 16 维属性，缺失值检查与插补前后统计都要记录。
- 生成统一且唯一的 `image_id/Seed编号/真峰编号`，同时保留原始编号与数据来源字段，确保可追溯。
- 更新图片与 JSON 路径为可移植的相对路径，不写死另一台电脑的盘符。
- 先查精确重复：Feature ID、文件 SHA256、图片 SHA256。
- 再查近重复：同一来源内 m/z 接近（建议 5 ppm 内）、RT 接近（建议 2 秒内），以及图片感知哈希高度相似。近重复组成同一 group，后续不得跨 split。
- 若旧、新标注对同一候选发生冲突，输出冲突表供人工确认，不得静默覆盖；在确认前优先保留旧最终人工版本并把该 group 排除出 test。
- 若无重复，合并后的 Seed 数应为 `旧最终 Seed 数 + 4500`；若旧最终确为 15317，则应为 19817。

输出至少包括：

- 合并后的 Seed 主表；
- 合并后的人工真峰实例表；
- 修正后 PNG/JSON 数据目录；
- 重复与冲突审计；
- 16 属性 NaN/inf、min/quantiles/median/mean/max；
- 按来源、Seed 真值、框标签和困难类型的数量统计；
- 完整合并配置与 SHA256 自检报告。

## 四、主实验：样本级分层随机划分

主实验不要按整份 mzML 文件互斥划分。采用固定随机种子 `20260814`，以“图片/候选”为最小单位做 `70% train / 15% val / 15% test`：

- 同一图片的所有检测框必须在同一 split。
- 上一步识别出的重复/近重复 group 必须整体进入同一 split，避免数据泄漏。
- 尽量联合分层：`Seed真假标签`、是否含检测框、`True_Peak/OUT_FIG`、来源 mzML、旧/新批次、困难类型（NOISE/JAG/PLAT/SHOULDER/DOUBLE/EDGE 等）。
- 样本量足够的每个来源应按约 70/15/15 分布到三个 split；极小来源不能机械拆散时记录偏差。
- 稀有 `OUT_FIG` 和正样本要用确定性分配保证 val/test 可评估，但不得复制样本。
- test 一次生成后锁定，不参与阈值选择、早停、属性选择或超参数调整。
- 属性缺失值插补器、标准化器和任何统计变换只能在 train 上拟合，再应用到 val/test；保存拟合参数和缺失掩码统计。

输出 `train/val/test` 的 CSV/JSONL，以及一份审计报告，至少逐 split 列出：

- 图片数、Seed 正/负数及比例；
- `True_Peak/OUT_FIG` 框数；
- 单框/多框图数量；
- 每个 mzML 来源数量；
- 旧数据与新增 4500 批次数量；
- 各困难类型数量；
- 16 属性缺失与分布；
- group 泄漏检查结果（必须为 0）；
- 三个 split 的图片路径与 ID 交集（必须为 0）。

## 五、跨域实验：另建来源留出清单

在不改变主实验锁定 test 的前提下，额外创建 `cross_domain` 清单：

- 按完整公开数据集/实验来源分组，而不只是随机挑单张图片。
- 同一公开项目的技术重复、同一仪器批次或明显相关 mzML 不得分散到训练域和测试域。
- 跨域测试来源完全不能进入跨域训练/验证。
- 选择时兼顾正负样本、困难假峰和仪器/基质差异，并输出选择理由及各域统计。
- 这套清单用于后续单独的跨域实验，不替代主实验的随机分层 test。
